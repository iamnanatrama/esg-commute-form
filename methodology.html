Calculation Methods

สูตรหลักที่ใช้อยู่ในระบบปัจจุบัน

Employee Commuting CO2e/year = Round-trip distance (km/day) x Annual work days x Vehicle emission factor (kgCO2e/km) / Carpool share Annual work days = Selected work days per week x 50 Septic CH4 kg = Employees x Work days x BOD x B0 x MCF x Correction factor Septic CO2e kg = CH4 kg x GWP CH4 Scope 2 Electricity CO2e = Electricity usage (kWh) x Grid emission factor (kgCO2e/kWh)

Audit Evidence & Traceability

สิ่งที่ควรเก็บเพื่อให้ทวนสอบย้อนหลังได้

ข้อมูลกิจกรรมที่ต้องเก็บ
  • Commuting: timestamp, employee id/name, branch, department, distance, work days, vehicle, fuel, carpool
  • Septic: month, branch, employee count, work days, BOD, B0, MCF, GWP, correction factor
  • Electricity: billing month, meter/bill reference, kWh, grid EF, source document
Factor snapshot ที่ควรแนบใน record
  • factor value ที่ใช้ ณ วันที่บันทึก
  • factor version/year/effective date
  • source document หรือ approval reference
  • ผู้อนุมัติ/ผู้ตรวจสอบค่า factor
Revision control
  • เมื่อเปลี่ยน factor ต้องออก version ใหม่
  • ห้ามแก้ผลคำนวณย้อนหลังโดยไม่บันทึกเหตุผล
  • รายงานเก่าต้องอ้าง factor snapshot เดิม
Current gap
  • ต้องแนบเอกสารอ้างอิง/อนุมัติสำหรับ factor ที่ใช้จริง
  • ควรเพิ่ม Google Sheet tab: emission_factors, source_documents, audit_log
  • ควรเพิ่ม field factor_version ใน record ทุก module
